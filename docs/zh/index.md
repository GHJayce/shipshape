    -   icon: 👁️
        title: 一览全局
        details: 业务流程不再隐藏在层层嵌套的 if/else 和 foreach 中，而是通过清晰的流程定义直接展示在代码最上层。

        title: 易于扩展
        details: 新增或修改某个业务环节，只需添加/替换对应的节点类，无需改动主流程代码，符合开闭原则。
    -   icon: 📦
        title: 即插即用
        details: 不依赖任何框架，Composer 安装后即可在任意 PHP 项目中使用。
    -   icon: 📜
        title: 保留 PHP 原生习惯
        details: 你依然可以用 if、switch、循环等原生语法，但将它们封装在节点内部。主流程只负责“编排”，不掺杂具体实现。
    -   icon: 📦
        title: 性能优越
        details: 执行过程即foreach，几乎没有性能损耗。

# 介绍

Shipshape 是一个轻量级业务编排工具。将一段复杂的业务功能，拆解为多个动作，每个动作只做一件事。让你在保持代码从上到下书写习惯的同时，实现逻辑的一目了然、易于扩展、极速定位。
